# Experimental pet designer

This renderer-only lab turns a user's pet identity choices into a hatch-pet v2 generation brief and makes the required atlas contract visible before art is generated.

```bash
npm run dev:pet-designer
```

Open `http://127.0.0.1:5176/?experimental=pet-designer`.

The lab does not package a sprite. The next stage uses the hatch-pet workflow to generate the canonical base, nine standard animation rows, two look rows, and the required deterministic and visual QA artifacts.
